PROBLEM STATEMENT

First-day setup is tribal knowledge.

New engineers join an unfamiliar repository and piece together environment setup, architecture decisions, and the first task from scattered chat threads and aging documents.

THE CURRENT WORKAROUND

Ask in chat, copy snippets into local notes, and hope the answer matches the current branch.

TARGET USERS

Distributed product teams with 3–8 contributors using different AI coding agents.

USER PAIN

Repeated onboarding, conflicting assumptions, duplicate work, and risky integration surprises.

DEMO OUTCOME

From accepted plan to one focused first task.

A new teammate joins, claims an unowned task, and hands their local agent an up-to-date context pack.

MEASURABLE · ONE TASK CLAIMED WITHOUT DUPLICATION
PRODUCT SCOPE
P0

Shared workspace, approved brief and decisions, safe task claiming, scoped work, context packs, integration checklist.

P1

Realtime updates, GitHub OAuth, read-only MCP tools, advanced reporting.

P2

IDE extensions, remote agent execution, auto-merge, chat/video, AI-generated architecture.

PRIMARY JOURNEY

One path through the product

OWNER → CONTRIBUTOR → REVIEWER
  1. 01
    Agree the problem

    Lead publishes the brief and the team accepts the measurable outcome.

  2. 02
    Approve the boundaries

    Decisions define the data model, trust boundaries, and integration shape.

  3. 03
    Claim a safe slice

    A member claims one task; overlapping paths surface as advisory warnings.

  4. 04
    Build with current context

    Contributor exports a task-specific pack to their local agent and returns with evidence.

  5. 05
    Review, integrate, release

    Human review and checks remain in GitHub; VibeCrew tracks readiness and handover.

OBSERVABLE ACCEPTANCE

✓ Two signed-in members see the same accepted project data.

✓ Simultaneous task claims cannot both succeed.

✓ An accepted decision increments context revision.

✓ A stale task context is called out before implementation.

These are target criteria from the brief; they are not verified in this preview.
